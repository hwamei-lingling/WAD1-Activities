# Activity 4: Interactive Score Tracker

A simple score tracker built with HTML, CSS, and vanilla JavaScript. This is my first Git repository, created for the Week 4 lesson on version control and JavaScript logic.

## Features

- Displays a score that starts at 0
- **Add point** increases the score by 1
- **Subtract** decreases the score by 1
- **Reset** sets the score back to 0
- Shows a message based on the score:
  - 10 or higher: "Outstanding performance!"
  - Below 0: "Below expectations!"
  - Otherwise: "Keep going to raise your score!"

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure |
| `style.css` | Page styling |
| `script.js` | Score logic and button events |

## How to run

1. Download or clone this repository.
2. Open `activity-4/index.html` in any web browser.

No installation is needed.
